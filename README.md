# 应届大学生驯服野生AI修仙 · 在线阅读

一个纯静态的阅读页面，没有任何依赖，不需要构建工具。

## 怎么看

- 在线：仓库启用 GitHub Pages 后访问对应地址
- 本地：把仓库下载下来，双击 `index.html` 就能读（数据编译成 JS，不走 fetch，所以 `file://` 也能用）

## 阅读功能

- 三套主题：夜、纸、日
- 字号、行距、页宽、宋体/黑体可调，设置存在浏览器本地
- 目录抽屉带搜索，读过的章节会变暗
- 记住上次读到哪一章、滚到哪个位置
- 键盘：`←` `→` 翻章，`空格` 翻页，`T` 目录，`S` 设置

## 目录结构

```
index.html        页面
assets/style.css  样式（主题与排版变量都在这里）
assets/app.js     交互
data/book.js      正文数据，由稿件仓库的 build_site.py 编译生成
```

`data/book.js` 是生成物，不要手改——改了下次编译会被覆盖。正文的唯一来源是稿件仓库里的 `正文/*.md`。
